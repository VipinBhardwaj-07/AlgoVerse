Dijkstra's Algorithm: Shortest Paths with Nonnegative Weights

Dijkstra's algorithm computes the shortest distance from one source to every reachable vertex when edge weights are nonnegative. A min-heap helps choose the next most promising vertex.

Repeatedly settle the closest known vertex

Initialize the source distance to zero and all other distances to infinity. Each time an edge u → v of weight w is considered, test whether reaching v through u improves its distance: dist[u] + w < dist[v]. This update is called relaxation.

When the smallest tentative distance is removed from a min-priority queue, it is safe to settle that vertex because all remaining paths must extend a distance that is no smaller, and edge weights cannot reduce it. This reasoning is exactly where the nonnegative-weight requirement matters.

Python implementation

import heapq
from math import inf

def dijkstra(graph, source):
    distance = {node: inf for node in graph}
    distance[source] = 0
    heap = [(0, source)]
    while heap:
        cost, node = heapq.heappop(heap)
        if cost != distance[node]:
            continue  # ignore an outdated heap entry
        for neighbor, weight in graph[node]:
            candidate = cost + weight
            if candidate < distance[neighbor]:
                distance[neighbor] = candidate
                heapq.heappush(heap, (candidate, neighbor))
    return distance

Many standard heaps do not support decrease-key, so this implementation inserts an improved pair and skips stale entries when they are later popped. To reconstruct a path, also store parent[neighbor] = node whenever the distance improves, then follow parents backward from the destination.

Complexity and when not to use it

With adjacency lists and a binary heap, the usual bound is O((V + E) log V) (often written O(E log V) for connected graphs), with O(V + E) graph storage plus distance/heap state. For an unweighted graph, BFS is simpler and runs in O(V + E). With negative edges, use Bellman-Ford or another algorithm designed for those weights; Dijkstra may permanently settle a node too early.

  • Validate that input weights are nonnegative when this is a precondition.
  • Consider unreachable nodes: their distance remains infinity.
  • If only one destination matters, the algorithm can stop when that destination is settled.
  • For all-pairs distances, consider whether repeated Dijkstra or an all-pairs algorithm fits the graph size.

Core distinction: BFS minimizes number of edges; Dijkstra minimizes total weight for nonnegative weighted edges.
